# Jolly

Drop Meta's real Jolly artwork here as `jolly.png`, then run `./render.sh`.
`build.py` picks it up automatically and composites it into both banners.

Nothing in this repo draws a stand-in. Jolly is Meta's character, so either
the real asset is used or none is.

Framing note: Jolly is the avatar of **Muse**, Meta's personal AI agent.
**Muse Code** is the terminal coding agent powered by Muse Spark. The banners
pair Jolly with a terminal and Kong rather than presenting Jolly as Muse
Code's mascot.
